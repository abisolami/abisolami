### Featured Projects

**[Product Demand Forecasting Dashboard for SMEs](https://github.com/abisolami/Product_demand_predictive_model)**
XGBoost + Random Forest model classifying inventory demand into 3 tiers — 87% accuracy, 22% reduction in forecast error. Deployed as an interactive Streamlit dashboard. Also published as a peer-reviewed paper.
`Python` `XGBoost` `Streamlit` `Seaborn`

**[Lagos Apartment Rent Price Predictor](https://github.com/abisolami/lagos-rent/blob/main/Lagos_Rent.ipynb)**
Supervised regression model predicting rental prices across Lagos. Log transformation for interpretability, deployed as an interactive web app.
`Python` `Scikit-learn` `Streamlit`
